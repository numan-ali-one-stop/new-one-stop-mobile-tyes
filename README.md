# One Stop Mobile Tyres 24/7 — Website

Production website for One Stop Mobile Tyres 24/7, built with [Next.js](https://nextjs.org).

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

The main site pages live in `app/`, shared UI in `components/`, and shared business data (name, address, phone, response time) in `lib/constants.ts`.
